# flatrate-math
Benchmark math for flat-rate software subscriptions against the fully loaded cost of a senior developer hire.

Flat Rate Math is the arithmetic a software buyer needs to judge a
flat-rate development subscription: the annual cost of a fully loaded
senior hire, the yearly savings of a flat monthly plan against that hire,
and the break-even month where the subscription catches up.

It models the pricing of [PoketDev](https://poketdev.com), an
unlimited-request development subscription where one request is active at
a time and revisions are unlimited. The crate ships with unit tests and
no external dependencies.
